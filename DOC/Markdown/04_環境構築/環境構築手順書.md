- OS: Windows 11
- .NET SDK: `10.0.204`（`10.0.102` も併存）
- Visual Studio: Community 2026 (v18.5)、ASP.NET と Web 開発ワークロード導入済み
- 追加インストールは不要な状態からスタート

## 手順

### 1. Blazor Web App プロジェクトの新規作成

- [ ] Visual Studioを起動し「新しいプロジェクトの作成」を選択
- [ ] テンプレート検索で `Blazor Web App` を選択
- [ ] プロジェクト名・保存場所: `SRC/RiskMap.Web`（リポジトリ直下の `SRC/` を指定）
- [ ] 追加情報画面での選択内容:
  - フレームワーク: `.NET 10.0`
  - 認証の種類: `なし`
  - HTTPS用の構成: チェックあり
  - Interactive render mode: `Server`
  - Interactivity location: `Global`
  - サンプルページを含める: チェックあり（動作確認用にCounter/Weatherページを残した）

> ステータス: 実施済み（`SRC/RiskMap.Web` に問題なく作成）

### 2. 既定テンプレートの起動確認（F5）

- [ ] F5でデバッグ起動し、既定のホームページ/Counter/Weatherページがブラウザで表示されることを確認

> ステータス: 実施済み（Counter/Weatherページとも問題なく表示・動作確認できた）

### 3. Leaflet.js導入

- [x] `wwwroot` 右クリック →「追加」→「クライアント側ライブラリ」
- [x] プロバイダー: `cdnjs`、ライブラリ: `leaflet@1.9.4`、ターゲット: `wwwroot/lib/leaflet/`
- [x] 「インストール」実行 → `wwwroot/lib/leaflet/` 配下にjs/css/画像ファイルが展開されたことを確認

> ステータス: 実施済み（問題なく展開できた）

### 4. 地図表示コンポーネントの実装

未実施。以下のサブステップで進める予定（**次回はここから**）。

- [ ] 4-1. `App.razor` の `<head>` に Leaflet CSS（`_content/...` ではなく `lib/leaflet/leaflet.css` への `<link>`）を追記
- [ ] 4-2. `App.razor` の `</body>` 直前に Leaflet JS（`lib/leaflet/leaflet.js`）への `<script>` を追記
- [ ] 4-3. 地図初期化用のJSモジュール（例: `wwwroot/js/map.js`）を作成し、Leafletで地図を初期化する関数を書く
- [ ] 4-4. 地図表示用のRazorコンポーネント（例: `Components/Pages/Map.razor`）を作成し、`IJSRuntime` 経由で4-3のJS関数を呼び出す
- [ ] 4-5. ナビゲーションメニューに地図ページへのリンクを追加し、F5で地図（OpenStreetMapタイル）が表示されることを確認
