## 画面遷移フロー（概要・テキストボックスの文言と画面内容からの推定）

```mermaid
flowchart TD
    Login[ログイン画面] -->|ログイン成功| Map[地図閲覧画面]
    Login -->|ログイン失敗| Login
    Login -->|パスワードをお忘れの方リンク押下| PwReset[パスワード再設定: 秘密の質問]
    PwReset -->|秘密の質問が間違っていた場合| PwReset
    PwReset -->|秘密の質問をお忘れの方| MailSent[パスワード再設定: メール送信済み]
    MailSent -->|メール内に記載されたURLを押下| PwResetForm[パスワード再設定: 新パスワード入力]
    Login -->|新規アカウント登録リンク押下| Signup[新規アカウント登録]

    Map -->|RiskMapロゴ押下| Map
    Map -->|ピン押下| PinDetail[ピン押下時: 危険情報の詳細]
    Map -->|危険度ランキングリンク押下| Ranking[危険度ランキング]
    Map -->|絞り込み検索リンク押下| Search[絞り込み検索]
    Map -->|検索ボタン押下| Search
    Map -->|通知設定リンク押下| MyArea[Myエリア設定]
    Map -->|新規投稿押下| NewPost[新規投稿用画面]
    PinDetail -->|コメント投稿押下| Comment[コメント追加用ポップアップ]
```

※ この図は自動抽出した操作ラベルと画面キャプチャの内容から人手で推定した概略フローであり、元の`.xlsx`/`.pdf`にある正確な矢印の接続を保証するものではない。正式な遷移仕様として扱う場合は原本を確認すること。
