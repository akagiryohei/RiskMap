# 画面設計書

> 元ファイル: `DOC/基本設計書/画面設計書.xlsx`
>
> 元ファイルはExcelのセル位置を使った画面モックアップ（図形的レイアウト）のため、セルの座標情報はマークダウンでは表現できない。ここでは各画面レイアウトに含まれる表示要素・文言を、シート内での出現順に箇条書きとして書き出す（一部シートは同じレイアウトが横に複数（差分比較用など）並んでいるため、見出しが重複する場合は内容をまとめて記載している）。
