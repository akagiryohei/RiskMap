# 機能一覧

> 元ファイル: `DOC/基本設計書/機能一覧.xlsx`

| 大分類 | 機能名 | 内容 | 備考 |
| --- | --- | --- | --- |
| 地図機能 | 危険スポット投稿 | 地図上にピンを立てて、危険・不快な体験を共有できる | 卑猥な声掛け、つきまといなど |
| 地図機能 | 投稿閲覧 | 他ユーザーが投稿したスポットを確認できる | 危険度や発生日で絞り込み |
| 地図機能 | 危険レベル表示 | ピンの色やアイコンで危険度を表現 | 視覚的にわかりやすい |
| 情報共有 | コメント機能 | 投稿に対して補足や注意喚起を追加できる | 気軽に書き込みしやすくする |
| 情報共有 | 写真・証拠添付 | 投稿に画像やテキストを添付できる | 個人特定情報は注意 |
| 通知機能 | エリア通知 | 自分の登録エリアで新規投稿があれば通知 | 在住・通学エリア向け |
| 通知機能 | 現在地付近アラート | 移動時に近くに危険スポットがあると通知 | GPSを利用 |
| ユーザー管理 | アカウント登録/匿名投稿 | ニックネームや匿名で利用可能 | 個人情報保護重視 |
| ユーザー管理 | 通報/削除依頼 | 誤投稿や悪意ある投稿を通報 | 管理者審査で削除 |
| 分析・便利機能 | 危険度ランキング | 地域ごとの危険件数をランキング表示 | 治安の傾向を把握できる |
| 分析・便利機能 | 絞り込み検索 | 時期・カテゴリ・場所で投稿を検索 | 「夜間のみ」「声掛けのみ」など |

| ログイン機能 | 登録 |  |  |
| ログイン機能 | パス再設定 |  |  |
