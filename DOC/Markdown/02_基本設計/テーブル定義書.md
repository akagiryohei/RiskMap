## ER図（テーブル関連、推定）

`ER図(RiskMap)` シートは図形（テーブルボックスと関連線）で構成されており、線の接続関係はテキスト抽出では失われるため、各テーブルの列名から読み取れる推定の関連を以下に示す（FK列自体は上表では未設定）。

- `users.secret_tips_id` → `secret_tips.id`
- `users.area_id` → `area.id`
- `post.prefecture_id` → `prefecture.id`
- `post.city_id` → `city.id`
- `post.category_id` → `category_master.id`
- `comment.post_id` → `post.id`
- `comment.poster_id` → `users.id`
- `post_delete_request.post_id` → `post.id`
- `comment_delete_request.comment_id` → `comment.id`
- `prefecture.area_id` → `area.id`

## 雛形シートについて

`雛形` シートは新しいテーブルを追加する際に複製して使う空のテンプレート（項番1〜20の空行のみ）。
